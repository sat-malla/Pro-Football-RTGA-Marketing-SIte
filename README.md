## About

This is the public-facing marketing and landing page for Pro Football RTGA to learn all about what the app does, see it in action, and (once published) download it. Explore the actual [application repo](https://github.com/sat-malla/nfl-randomteam-analysis), which contains the real product and the real full-stack stuff: the React Native app, the Go backend, and the Python ML microservices behind team generation, analysis, simulation, and optimization.

## Deployment

This site auto-deploys to [Vercel](https://vercel.com) on every push to `main`. No manual deployment steps are needed for changes merged into that branch.
